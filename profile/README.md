# Async Digital Ltd

**Async Digital builds software.** A one-person studio testing, in the open,
what really changes when AI can write the code.

The claim everywhere right now is that AI replaces the engineer. What we keep
finding is that it moves the engineer instead: from writing the code, to
building the system that writes and checks it, to deciding whether to trust
what comes out. That last decision is the part that does not automate.

## The work

**Ordova** is the system that does the rest. It is an operating system for
solo software work: session handoff, governed memory, and a guard estate that
decides which checks are crucial when nobody is reading every line of
output. It is private, and how it works is documented publicly at
https://ordova.async-digital.com

**Audient** is a macOS app that uses on-device AI to transcribe and search
audio and video you give it. On the Mac App Store.
https://audient.async-digital.com

**Working notes and case studies.** Everything above gets written up as it
breaks, including the parts that did not work.
https://async-digital.com/notes/
https://async-digital.com/case-studies/
