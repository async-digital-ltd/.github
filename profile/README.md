# Async Digital Ltd

**Async Digital Ltd reviews websites and apps against the Welsh Language Standards, and builds bilingual websites, apps, and MCP apps for AI assistants, for organisations that serve the public in Wales. Its director, Rob Nash, is accountable for every project and signs off before anything ships.**

## The work

**Ordova** is the system the studio runs on. It is an operating system for
solo software work: session handoff, governed memory, and a guard estate that
decides which checks are crucial when nobody is reading every line of
output. It is private. There is a short overview at
https://async-digital.com/ordova/

**Audient** is a macOS app that uses on-device AI to transcribe and search
audio and video you give it. On the Mac App Store.
https://audient.async-digital.com

**Quill** is a command-line tool for macOS that transcribes audio and video
on-device and writes the words out as markdown. Your audio is not sent
anywhere. It is open source under the MIT licence.
https://github.com/async-digital-ltd/quill-cli

**Seen to Fail** is a small web app that records whether each automated check
has ever been seen to catch a planted defect, and publishes a ledger of its
own checks. Coding agents built it under the owner's direction, and the
repository shows how that work was checked. It is open source under the MIT
licence.
https://github.com/async-digital-ltd/seen-to-fail

**Mastering the AI Coworker** is a book of principles for running an AI
coworker in a one-person studio, written from the practice above.
https://coworker.async-digital.com

**Working notes and case studies.** Everything above gets written up as it
breaks, including the parts that did not work.
https://async-digital.com/notes/
https://async-digital.com/case-studies/

## This organisation on GitHub

Most of the work is private. Quill and Seen to Fail are published here in
full. The other public repositories are Swift packages and supporting
components, not the systems described above.
